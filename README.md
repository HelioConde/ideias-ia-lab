# PratoPronto

Planejador semanal de refeições, orçamento e lista de compras.

MVP fullstack preparado para repositório independente.

## Stack
- HTML/CSS/JavaScript
- Supabase + `pizzaria-db`
- RLS
- GitHub Pages
- GitHub Actions

## Segurança
Apenas publishable key no navegador. Nunca use `service_role` no frontend.
