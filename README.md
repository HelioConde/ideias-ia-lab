# Ideias+ — 10 protótipos web

Dez conceitos independentes em uma coleção estática que pode ser publicada no GitHub Pages. Abra `index.html` para explorar. Cada pasta numerada contém um site navegável.

## Sites

1. PostPilot — calendário de conteúdo
2. VagaCerta — organizador de candidaturas
3. FalaPro — treino de entrevista em inglês
4. MontaPC — planejamento de configuração
5. GameRadar — lista de desejos e alertas manuais
6. AgendaLeve — agenda local de horários
7. Perto — catálogo demonstrativo de serviços
8. PratoPronto — planejamento semanal de refeições
9. Revisa — organização de estudos
10. DocPronto — estrutura para rascunhos de documentos

## Executar

Abra `index.html` em um navegador ou sirva a pasta com um servidor estático. Os registros são salvos em `localStorage`. Não há serviços externos, geração de IA real, contas, pagamentos, scraping ou consulta de dados ao vivo. Os dados e resultados são demonstrativos; integrações devem ser configuradas antes de qualquer uso comercial.
