# FalaPro

Treino guiado de entrevistas em inglês com feedback e histórico.

MVP fullstack preparado para repositório independente.

## Stack
- HTML/CSS/JavaScript
- Supabase Auth + banco compartilhado `pizzaria-db`
- RLS nos dados privados
- GitHub Pages
- GitHub Actions

## Segurança
O navegador usa apenas a publishable key. Nunca use `service_role` no frontend.
