# Perto

Marketplace local moderado de profissionais e pedidos privados.

MVP fullstack preparado para repositório independente.

## Stack
- HTML/CSS/JavaScript
- Supabase Auth + `pizzaria-db`
- RLS
- GitHub Pages
- GitHub Actions

## Segurança
Somente publishable key no navegador. Segredos administrativos ficam fora do frontend.
